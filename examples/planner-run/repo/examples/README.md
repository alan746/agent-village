# Planner Examples

This directory contains example datasets for `planner`:

- `sections.csv`: A complete course schedule catalog with ~8 university courses across science, engineering, and humanities, with multiple sections and meeting times.
- `malformed_sections.csv`: An invalid sections file with malformed time values demonstrating error rejection.
- `exams.csv`: Exam schedules (`course,date,start,end`) including intentional exam clash scenarios for M4 testing.
- `buildings.csv`: Campus building locations with latitude/longitude coordinates for walking distance / travel time calculations (M4).
